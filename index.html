🚀 Quick start

  1. Download Aion2.Updater.zip and extract it to its own folder. Don't run it from inside the archive.
  2. Choose your game resolution before running the updater — it can't be changed after installation. Windowed and fullscreen both work.
  3. Run Aion2.Updater.exe and log in with your card key (“CARD NUMBER” → “LOGIN”). New users can claim a free 3-hour trial card. Buy cards on unicom.market.
  4. Launch AION 2 and enter your character. The Aion Helper window opens automatically; press F10 if it doesn't. Turn on the features you need.

System requirements: Windows 10/11 (64-bit), VC++ runtime libraries (install them with one click in the updater's ⚙ menu). If the game crashes on start, see Setup checklist & crash fixes.

After every game update run the updater again, otherwise the helper shows “Update required” and stays off until you do.

Running without the bot / uninstalling

To stop the bot for a session, just close the updater or don't launch it — the game itself keeps working. To remove the helper from the game entirely: open Aion2.Updater.exe, click the ⚙ menu (top-right corner) and choose Uninstall — it removes the helper from every game folder it found. After that the client is clean; run the updater again (F10 opens the helper) whenever you want the bot back.

🖥 e Control Center (Aion Helper Control Center) is the desktop tool for managing many accounts. Add your accounts, then log them into the game in batches, start daily activities with one click, and see every account's status, Kinah and latest message in a single table.

← Table of contents
  • Taiwan · Korea · Global

Where to find it

  1. Updater
  2. Start Control Center
  3. Accounts

The icon bar on the left shows, from top to bottom: Accounts, Captcha, Daily Records and Feedback. The ⚙ at the bottom opens Settings.

What it does

  • Add an NC email account, or sign in through Google, Steam, Apple and other platforms. The server is detected automatically
  • Select several accounts and start or stop them in one go
  • Click “Start Daily Activities” and every enabled account follows the workflow you arranged
  • The account list shows running status, account status, Auction access left, Kinah and work/rest countdowns
  • Double-click an account to see its characters: level, combat power, Kinah, daily Kinah cap progress and gathering time
  • Right-click an account to pin it, start combat or gathering, edit the character config, view logs, edit or delete

How to use it

  1. Click “Start Control Center” in the Updater.
  2. Click “Add Account” and choose “NC Email Account” or a platform. For an email account, enter the email and password, click “Verify”, then “Save”. Global accounts also need a region.
  3. Go to “Settings › General” to check the game path and game language.
  4. Turn on the account's Status switch, select the accounts and click “Start Selected Accounts”, or just click “Start Daily Activities”.
  5. Watch progress in the list, and double-click an account for details.

Settings explained

Setting What it does
Add Account Supports NC email accounts and platform accounts (Google, Facebook, Apple, Twitter, LINE, Steam, VK and more). Platform accounts sign in through a pop-up browser, and your password is not saved.
Global server region North America - East, North America - West, Europe, South America or Asia.
Status switch Decides whether this account takes part in batch starts and daily activities.
Start Daily Activities Every enabled account runs the workflow in “Settings › Daily Activities”. Click again to stop.
Start Selected Accounts / Stop Selected Hold Shift or Ctrl to select several accounts, then log them in or close their games in one go.
Right-click › Character Config Save the current character's settings as the default config, or apply them to your other online characters in one click.
Right-click the table header Show or hide columns such as server, account status, Kinah and latest message. Column widths are remembered.
Note Add a note to an account. Hover over the account to read it.

Good to know

  • Windows 10 is recommended.
  • If you use a network accelerator, add the Control Center to its accelerated list too, or logins may fail.
  • Multi-account launching uses the game client downloaded through the Purple platform. Steam accounts can be added too and log in through Purple.
  • If you only run one game, you can skip the Control Center and press F10 in the game to use the helper.

Building your own rotation

There is no rotation editor. Rotations are built in, one per class — the 9 October update added the last two classes, so every class is now supported.

The only place you can influence it is the right mouse button. As the developer put it: the right button is where you drag your custom skills, and it will cast them as long as you have mana — if you don't like the built-in rotation, build a macro and put it on the right button.

So the procedure is:

  1. Build a macro with your skills in the game's macro editor.
  2. Drag it into the slot bound to the right mouse button.
  3. It will be cast from there whenever you have mana.

Two things worth knowing. First, the official position is that you should just use the default — the custom slot is a workaround, not a supported feature. Second, there is only one custom slot, the right button; people have asked for one or two extra keybinds, but nothing has been confirmed.

An empty right slot is the most common cause of the bot standing still and doing nothing — that is the first thing to check when auto-combat looks broken.

Do not confuse this with skill-point allocation. That is also automatic, from a per-class template, and cannot be edited by hand. For that, the developer offered a different route: send an account with manually allocated points, and he will take a snapshot and use it as the template for that class. That concerns skill points, not cast order.

CAPTCHA recognition: troubleshooting

Troubleshooting order

  1. Confirm the Control Center is running. Only the Control Center processes CAPTCHAs. A game client with the in-game helper alone will not solve them.

  2. Accelerate the Control Center, not the game. Route the Control Center through an accelerator. Xunyou (迅游) in routing mode (路由模式) is the setting reported to fix the "digits instead of letters" and "solver connection failed" cases. Accelerating the game client does not help — the traffic that matters belongs to the Control Center.

  3. Check reachability of the Hong Kong, Japan and Singapore nodes. If these are blocked, the CAPTCHA image never reaches the solver and no solution can return.

  4. Increase the game window resolution. At low resolution the captured CAPTCHA image is unusable, and recognition fails even with a working solver connection.

  5. Check the hosts file. Pirated or repacked updaters write domain blocks into Windows. Delete C:\Windows\System32\drivers\etc\hosts, then reopen Aion Updater.

Warning

Machines that have run pirated builds are hardware-banned from all aion.onl products. Buying a legitimate key afterwards does not lift the ban, and the affected key is banned as well.
